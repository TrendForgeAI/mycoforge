# Impact Mapping

**Kategorien:** strategic-planning, requirements | **Rollen:** planner, product-owner | **Tier:** 2
**Referenz:** Gojko Adzic — *Impact Mapping* (2012)

## Core Concepts — 4 Ebenen

| Ebene | Frage | Beispiel |
|-------|-------|---------|
| **Goal (Why?)** | Welches Business-Ziel? | "Umsatz um 20% steigern" |
| **Actors (Who?)** | Wer kann das Ziel beeinflussen? | Nutzer, Partner, Admins |
| **Impacts (How?)** | Welche Verhaltensänderungen sind nötig? | "Nutzer kaufen häufiger" |
| **Deliverables (What?)** | Welche Features ermöglichen diese Änderungen? | "One-Click-Checkout" |

**Mind-Map-Format:** Ziel → Akteure → Impacts → Deliverables

**Hauptvorteil:** Features lassen sich bis zum Business-Ziel zurückverfolgen — "Why are we building this?"

## Wann einsetzen

- Wenn Stakeholder über Prioritäten uneinig sind
- Wenn Features vom Business-Ziel entkoppelt drohen zu sein
- MVP-Definition: nur Deliverables die direkt auf Goal einzahlen
- Scope-Creep verhindern

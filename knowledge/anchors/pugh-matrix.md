# Pugh Matrix

**Kategorien:** strategic-planning | **Rollen:** planner, architect, team-lead | **Tier:** 2
*Pugh Decision Matrix, Pugh Controlled Convergence*
**Referenz:** Stuart Pugh — *Total Design* (1991)

## Core Concepts

| Begriff | Bedeutung |
|---------|-----------|
| **Matrix Layout** | Kriterien als Zeilen, Alternativen als Spalten |
| **Reference (Baseline)** | Eine Alternative als Referenz — Score: S (same) |
| **Relatives Scoring** | Jede Alternative gegen Referenz: `+` (besser), `S` (gleich), `−` (schlechter) |
| **Summary Rows** | Σ(+), Σ(−), Σ(S), Net Score je Alternative |
| **Hybrid Solutions** | Stärken verschiedener Alternativen kombinieren |

## Varianten

| Variante | Einsatz |
|----------|---------|
| Unweighted 3-Point | Standard, schnell |
| Weighted 3-Point | Kriterien mit Wichtungsgewichten (Six Sigma) |
| Weighted 5-Point | Feinere Granularität bei eng beieinanderliegenden Alternativen |
| Pugh Controlled Convergence | Iterativer Multi-Runden-Prozess |

## Wann einsetzen

- Mehrere ernsthaft in Frage kommende Alternativen
- Architektur- oder Technologieauswahl
- Team-Konsens bei unklaren Trade-offs
- Council-Diskussionen strukturieren

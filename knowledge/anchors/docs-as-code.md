# Docs-as-Code

**Kategorien:** documentation-practices | **Rollen:** developer, technical-writer | **Tier:** 2
**Referenz:** Ralf D. Müller — docToolchain; Anne Gentle — *Docs Like Code* (2017)

## Core Concepts

| Begriff | Bedeutung |
|---------|-----------|
| **Plain Text Formats** | AsciiDoc oder Markdown — versionierbar, diff-bar |
| **Version Control** | Dokumentation liegt im selben Repo wie der Code |
| **Automated Build** | CI/CD generiert HTML, PDF aus Quell-Dokumenten |
| **Diagrams as Code** | PlantUML, Mermaid, C4 als Code statt Bild-Dateien |
| **Pull Request Workflow** | Dokumentationsänderungen durch Review-Prozess |
| **Single Source** | Eine Quelle, mehrere Output-Formate |

## Wann einsetzen

- Technische Software-Projekte wo Docs mit Code synchron bleiben müssen
- Verteilte Teams die gemeinsame Dokumentationsstandards brauchen
- Wenn Dokumentation in Release-Prozesse integriert sein soll

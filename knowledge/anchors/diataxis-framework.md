# Diátaxis Framework

**Kategorien:** documentation-practices | **Rollen:** developer, technical-writer | **Tier:** 2
**Referenz:** Daniele Procida — https://diataxis.fr

## Core Concepts — 4 Dokumentationstypen

|  | Practical (Doing) | Theoretical (Understanding) |
|--|------------------|-----------------------------|
| **Learning Acquisition** | **Tutorials** — lernorientiert, für Einsteiger | **Explanation** — verständnisorientiert, konzeptuell |
| **Professional Application** | **How-to Guides** — aufgabenorientiert, spezifische Ziele | **Reference** — informationsorientiert, technische Fakten |

| Typ | Frage | Beispiel |
|-----|-------|---------|
| **Tutorial** | "Bring mich ans Laufen" | Getting Started Guide |
| **How-to Guide** | "Wie mache ich X?" | "Deploy to production" |
| **Reference** | "Was sind die Details?" | API-Dokumentation |
| **Explanation** | "Warum funktioniert das so?" | Architecture Overview |

## Wann einsetzen

- Vorhandene Dokumentation analysieren: welcher Typ fehlt?
- Neue Dokumentation planen: welchen Typ brauche ich?
- Wenn Nutzer sich in Docs verlieren — meist weil Typen vermischt sind
